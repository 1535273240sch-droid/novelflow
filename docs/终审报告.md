## 五、未验证项（如实清单）

1. **独立验证缺失**：无「未参与实现」的第二验证者复跑并写验证记录。这是本报告最大的缺口。
2. **人工真机冒烟缺失**：访谈式交互、点击式流程（故事框架/章节规划/工作流确认点/设置页）未由真人在界面里逐项走查。自动化只覆盖到主进程逻辑与构建/启动。
3. **macOS 未真机验证**：CI 能在 macOS runner 上构建出 dmg，但未在真实 macOS 上运行。
4. **docx 版式未逐段校验**：单测只断言产出合法 zip 容器且非空，未打开 Word 核对排版。
5. **长文本性能**：编辑器为按章加载，未做「整书级」压力测试；流式推全量快照在超长章可能偏重（DECISIONS 第 8 条已声明）。
6. **工作流真实模型端到端**：引擎逻辑用注入的 mock executor 全量单测；真实模型下的三模板整链未实跑（需要真实 Key 或 mock server 人工操作）。
