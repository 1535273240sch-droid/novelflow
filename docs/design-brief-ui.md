# NovelFlow UI 设计简报（古墨·卷二精修版）

> 本简报是 2026-10 界面精修的依据：色值、圆角、字体、动效与组件来源全部以本文件为准，
> 改界面先改这里，再改代码。

## 1. 产品定位

- 做什么：桌面端小说写作工作台（模型接入、Skill 改稿、框架门禁、工作流、导出）。
- 给谁用：网文/严肃小说作者，单人长时间（数小时/天）使用。
- 核心任务：打开项目 → 按框架与章节计划持续产出/打磨正文 → 导出发布。
- 平台：Windows 桌面（Electron），不支持移动端。

## 2. 技术栈

- 框架：Electron + Vite + React 18 + TypeScript（维持现状）。
- 样式：Tailwind CSS v4。调色板通过 `@theme` 重映射（slate→墨纸阶、blue→墨青、
  red→朱砂、amber→赭金、green→苔绿、white/black→纸/墨），组件可直接沿用语义化
  工具类；通用控件沉淀为 `nf-*` 组件类（`@layer components`），不引入组件库。
- 动效：纯 CSS（transition + keyframes），不引入 framer-motion——动效总量少，
  保持安装包与依赖干净。
- 后端 / 部署：无后端，本机运行；模型走用户自配的 OpenAI 兼容服务。

选择理由：①项目已有可用的 React 18 + Tailwind v4 底座，重砌栈是纯损耗；
②工具型桌面软件要的是稳定与信息密度，不是框架新鲜感；③动效 handful，
CSS 足够，零运行时依赖。

## 3. 视觉方向

- 风格名称与对标锚点：「羊皮卷·古墨」——纸张与排版语境（对标 Notion 文档页的
  安静排版 + 中文文房器物色）。创作工具的视觉语言应来自"纸与墨"，而非通用 SaaS。
- 色板（浅色·日读）：

| 名称 | 色值 | 用途 |
|---|---|---|
| 宣纸 parchment | `#f5ecd4`（页面）/ `#f7f0dd`（面板） | 背景、卡片 |
| 松烟墨 ink | `#2b2118`（主）/ `#52432f`（次）/ `#8a7350`（弱） | 文字三级 |
| 朱砂 cinnabar | `#9e2b25`（印）/ `#a63f33`（交互红） | 印章、危险、caret、选中底 |
| 赭金 ochre | `#97701f`（主）/ `#dcc178`（淡） | 警示、高亮、确认点 |
| 苔绿 moss | `#5c7335` | 成功、插入行、接受态 |
| 墨青 qing | `#3b5b62` | 链接感、信息徽标 |

- 深色（玄墨夜读）：页面 `#171208`、面板 `#211a0e`、文字 `#e8dcc0` / `#b3a37f`、
  朱砂提亮 `#d0685c`、赭金 `#dcc178`、苔绿 `#a3bd6d`、墨青 `#9fb4b1`。
- 字体：正文衬线栈 `'Iowan Old Style', 'Palatino Linotype', Georgia, 'Songti SC',
  SimSun, 'Noto Serif CJK SC', serif`；标题/徽记楷体栈 `'STKaiti', 'KaiTi', 楷体, serif`。
  字号层级仅五档：页面题 20px（楷）/ 节题 15px（楷）/ 正文 14px / 辅助 12px / 微注 11px；
  编辑器字号行距由设置驱动（默认 15px / 1.9）。
- 圆角、边框、阴影：卡片 10px、控件 6px、印章 6px；边框 1px 墨色 12–22% 透明度；
  阴影只用于浮层与主按钮（`0 2px 6px -3px rgba(40,25,10,.6)`），平面层级靠明度分层。
- 动效策略：唯一编排动效 = 打开项目时的「展卷」（工作区 clip-path 由中线向两侧展开
  约 700ms，配一次性墨色扫过）；其余只有操作反馈（按压位移 1px、页签下划线过渡、
  吐司上浮、流式墨点呼吸）。全局尊重 `prefers-reduced-motion`。

## 4. 布局构想

一句话：顶栏一枚印 + 一行楷体字标 + 分段页签；三栏工作区（树/正文/辅栏），
功能页统一「楷体题 + 毛笔线 + 卡片分节」。

```
┌──────────────────────────────────────────────────────────┐
│ [印卷] NovelFlow  ·  书名        [编辑器|框架|工作流|Skill|设置]  │
├────────────┬──────────────────────────────┬──────────────┤
│ 故事框架    │  章题（楷）      保存 · 复制全文   │ Skill│模型试写 │
│ 章节计划    │                              │──────────────│
│ 正文       │         正文编辑区             │  面板内容      │
│ （项目树）  │      （行距 1.9 · 界格留白）     │              │
├────────────┴──────────────────────────────┴──────────────┤
│ 路径 · 字数 · 自动保存 · 上次保存                            │
└──────────────────────────────────────────────────────────┘
```

## 6. 唯一记忆点

打开项目时的「展卷」：工作区自中线向两侧展开（clip-path 过场，约 0.7s），
只此一处编排动效；其余界面保持安静。

## 7. 反模板自查

- 「奶油底 + 衬线大标题 + 陶土橙」属已泛滥组合：本项目虽为暖纸底 + 衬线，
  但色系是文房器物色（松烟墨/朱砂/赭金/苔绿），配印章、毛笔线等只属于
  中文写作语境的元素，且装饰仅存在于欢迎页——按行业语境取材，不套通用模板。
- 无眉标（全大写字距小标签）、无 01/02/03 装饰编号、无逐块淡入上滑、
  无卡片统一悬停浮起、按钮后不加机械箭头。
- 删减：深色模式移除全部 `!important` 工具类覆盖（约 40 行 hack），改为
  `data-theme` 变量切换；颜色一律走设计变量，组件内不再散落硬编码色值。
